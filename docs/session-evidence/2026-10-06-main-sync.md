## 제한

- Chrome 위치는 출처 기반으로 제어한 입력이다. 실제 휴대전화 현장 GPS 검증과 구분한다.
- 공유 건물 좌표는 개별 출입구·실내 점포 좌표가 아니며 근처 파노는 점포 정면을 보증하지 않는다.
- 운영 환경의 지도/도보 provider 설정은 별도 확인이 필요하다. API 실제 값은 GitHub에 저장하지 않는다.
- 기존 PC의 상세 이미지/원시 응답/위키/로컬 학습 스킬은 로컬 자료다. 다른 환경의 재개는 이 문서, 추적 코드, GitHub 검사 링크로 시작한다.
