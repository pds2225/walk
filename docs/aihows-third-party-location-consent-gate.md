# AIHows 개인별 위치기록 제3자 제공 — 동의·검증 게이트

상태: **제공 보류**. 기존 K-Navi 위치정보 수집 동의는 서비스 개선용 수집·보관에 관한 것으로, AIHows에 개인별 GPS 원본을 제공하는 동의가 아님.

## 신규 방문객에게 별도로 고지·선택할 사항
- 제공받는 자: AIHows (계약상 정확한 법인명 및 사업자정보 확인 필요)
- 제공 목적: 망원 월드컵시장 PoC의 방문·이동 데이터 연계 분석
- 제공 항목: 개인별 위치 좌표(위도·경도), 정확도, 기록 시각, 서비스 내부 식별자(정말 필요한 항목만)
- 보유·이용기간: 제공받은 날부터 **최대 1년**, PoC 목적 달성·동의 철회 등 사유 발생 시 더 이른 시점에 파기
- 거부권: 별도 동의 거부 시 지도·길찾기 기본 기능 제한 없음
- 개인정보 보호법상 제3자 제공 및 개인위치정보 관련 법적 요건을 별도로 검토하고 실제 수령 법인·제공 범위를 확정한 후 고지문 게시

## 구현·운영 필수 게이트
1. 별도 명시적 동의(기존 수집 동의와 독립), 고지문 버전 및 동의 시각, 철회 시각을 서버에서 신뢰 가능하게 기록. 단순 클라이언트 localStorage 플래그만으로는 제3자 제공 근거를 입증하지 않음.
2. **동의 이후 새로 수집된** 위치 이벤트에만 검증 가능한 동의 식별자를 서버에서 연결. 기존 이벤트는 소급 제공 금지.
3. 철회 시 이후 제공 즉시 차단, 보유기간 만료 시 수령기관 파기 확인. 제3자 제공 내역·접근 감사 로그 기록.
4. 서버 간 인증키, 수령기관 범위 제한, 조회량·기간 제한, HTTPS, 재전송·재식별 제한 및 유출 대응 절차.
5. 데이터베이스 마이그레이션 적용 확인, 실제 브라우저에서 동의/거부/철회 E2E, 동의하지 않은 방문객의 이벤트가 API에 노출되지 않는지 검증.
6. 법인명·수령기관 계약·운영 환경변수·Supabase 운영 실데이터 및 수령 서버의 파기 약정이 확인되기 전 개인별 GPS API는 **배포/활성화하지 않음**.

## 현재 코드와의 차이
- `web/lib/wcmGeoConsent.ts`는 위치 **수집** 동의만 localStorage에 기록.
- `web/app/api/track/route.ts`는 `geo_consent=true`만 수집 검증하며 제3자 제공 동의 이력을 기록하지 않음.
- `web/app/worldcup-market/privacy/page.tsx`는 외부 수령기관·제3자 제공 목적을 고지하지 않음.
- PR #202는 개인 GPS 원본 API를 제거하고 점포별 익명 집계 API만 포함.

결론: **현재 DB에 기존 방문객의 AIHows 제3자 제공 동의가 존재한다는 근거 없음**. 현 상태에서 개인별 GPS 원본을 넘기면 안 됨. 익명 집계 명세는 `docs/poc-store-aggregates-api.md` 참조.
